# Desktop Commander Local Compact

**ChatGPTから、自分のWindows PCのファイル確認や開発作業を行うためのツールです。**

[導入手順](docs/SETUP.ja.md) · [困ったとき](docs/TROUBLESHOOTING.ja.md) · [開発者向け](docs/DEVELOPMENT.ja.md) · [元プロジェクト・ライセンス](NOTICE.md)

> **初期公開版です。** 現在使っているCompact版のソースと、再現用のスクリプトを公開しています。導入には自分用のOpenAIトンネルの設定が必要です。ZIPを展開するだけで接続できる製品ではありません。配布者のPCやアカウントへ接続するものではありません。

> **依存関係に既知の脆弱性があります。** 固定した上流版の検査でhigh 3件・moderate 4件が報告されています。現時点ではソース公開・検証向けの初期版です。初心者への一括導入を勧める段階ではありません。[検証結果と制約](docs/VERIFICATION.ja.md)を確認してください。

## 何ができる？

- フォルダーの一覧やテキストファイルを確認する
- 指示したファイルを編集する
- ターミナルでコマンドを実行する
- git・npm・テストなどの開発作業を行う

Compactは、自動表示されるプレビューを抑える変更の名前です。ファイル操作やターミナルの機能を残しています。**最初は、秘密情報を含まないファイルの読み取りから試してください。**

## どうつながる？

```text
ChatGPT → OpenAIのトンネル → 自分のWindows PC → Desktop Commander MCP
```

処理は接続先PCで行います。読み取った内容やコマンドの結果はChatGPTへ返ります。外部通信のない完全なローカル接続ではありません。Remote Desktop Commanderは使用しません。

## 導入前に確認すること

| 項目 | 条件 |
|---|---|
| PC | Windows、Node.js 24以降、インターネット接続 |
| ChatGPT | 自分の利用環境でカスタムMCPを追加・使用できること |
| 接続 | 自分用のSecure MCP Tunnelと必要な権限 |
| 利用中 | PCの電源・ネット接続・トンネルの稼働を維持 |
| 費用 | MITライセンスのソフト。ChatGPT・トンネルの契約、制限、通信費は別 |

トンネルの利用条件は [OpenAI公式ガイド](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels) を確認してください。無制限利用や、今後も追加費用がないことは保証していません。独自ドメインやVPSは、この構成には必要ありません。

**準備できたら → [導入手順を最初から読む](docs/SETUP.ja.md)**

## スマホからも使える？

そのChatGPTの画面で、作成したツールを呼び出せることが条件です。PCが起動していても、すべてのスマホ環境で使えるとは限りません。この公開版について、別アカウント・別PC・スマホでの接続確認は未実施です。

ローカル直結・接続先の自動切り替えは、この版には含みません。

## 知っておいてほしいこと

このツールはファイルを書き換えたり、コマンドを実行したりできます。管理者として起動せず、作業用フォルダーで始めてください。ファイル操作の許可フォルダー設定は、ターミナル操作を閉じ込めるセキュリティ境界ではありません。ChatGPT側の操作承認は確認する設定（prompt）を維持してください。
