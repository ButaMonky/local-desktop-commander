## 依存関係の検査

`npm audit --prefix dc-preview-lab/runtime-deps` は終了コード1。報告は **high 3件・moderate 4件、critical 0件**です。これは依存パッケージごとの集計で、実際の悪用成立を確認した件数ではありません。

- sharp：画像処理ライブラリーの既知の問題
- zod：大きな入力の検証時のメモリー消費
- glob / minimatch：探索中断・パターン処理の問題
- uuid（exceljs経由）：バッファー境界検査の問題
- Desktop Commander自体も依存元として集計に含まれます。

検査時点で固定した上流版には、npm auditが提示する自動修正はありませんでした。無理なメジャーバージョン上書きで動作を変えず、現状を公開しています。未知の画像や文書など、信頼できないファイルを処理する用途に安全だとは宣言していません。広く初心者へ導入する前に、依存関係の更新と互換性確認が必要です。

今回の変更はプレビュー表示と接続・起動処理が対象です。セキュリティ問題を修正した版ではありません。詳細は手元で同じnpm auditを実行して確認できます。
